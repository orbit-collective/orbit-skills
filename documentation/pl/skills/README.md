# Oficjalne skille

Orbit Skills dostarcza celowo mały katalog sprawdzonych skillów. Każda pozycja katalogu ma odpowiadający jej katalog w `skills/` i jest walidowana przed rozpoczęciem instalacji, aktualizacji, usuwania, podglądu lub wyświetlenia informacji.
